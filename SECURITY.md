# Security Policy

## Supported Versions

The following versions of Peptide Design Lab are currently receiving security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of our bioinformatics platform seriously. If you discover a vulnerability, please do not disclose it publicly. Instead, follow these steps:

1. **Email us**: Send a detailed report to security@peptidedesignlab.example.com (Placeholder).
2. **Details to include**:
    - Type of issue (e.g., SQL injection, XSS, unauthorized data access).
    - Location of the vulnerability.
    - Step-by-step instructions to reproduce.
    - Potential impact on scientific data integrity.

We will acknowledge your report within 48 hours and provide a timeline for remediation.
