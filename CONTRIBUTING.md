# Contributing to Peptide Design Lab

Thank you for your interest in contributing to the Peptide Design Lab. As an advanced bioinformatics platform, we maintain high standards for code quality, scientific accuracy, and system performance.

## Code of Conduct

We follow a professional code of conduct to ensure a welcoming and inclusive environment for all researchers and developers.

## How to Contribute

### 1. Reporting Bugs
- Use the GitHub Issue Tracker.
- Provide a clear and descriptive title.
- Include steps to reproduce, expected behavior, and actual behavior.
- Attach relevant screenshots or logs.

### 2. Feature Requests
- Describe the scientific or technical rationale for the feature.
- Explain the intended use case within the bioinformatics workflow.
- Provide examples of similar features in existing platforms if applicable.

### 3. Pull Requests
- Follow the existing architectural patterns (Monorepo: `core_engine`, `web_client`, `intelligence_layer`).
- Ensure all new features are accompanied by appropriate tests.
- Maintain the 'editorial' design aesthetic in the web client.
- Optimize for performance—avoid artificial loading delays.
- Update documentation in `README.md` or `AGENTS.md` if necessary.

## Development Setup

See the main `README.md` for architectural overview. Detailed setup instructions are omitted by design to maintain a clean research environment, but standard NPM/Python procedures apply within their respective directories.

## Scientific Integrity

All contributions involving biological data or AI models must be validated against peer-reviewed sources.
